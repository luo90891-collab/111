# 修仙游戏 - 网页版 MVP

一个完整的网页修仙游戏，采用科技风UI设计。

## 功能特性

### 1. 账户系统
- 用户注册和登录
- 本地存储认证
- 支持多角色

### 2. 角色创建
- 3个宗门选择：剑宗、符宗、丹宗
- 每个宗门有独特的特殊技能
- 角色基础属性初始化

### 3. 属性系统
- **基础属性**：生命值、灵力、攻击力、防御力、速度
- **等级系统**：通过战斗获得经验升级
- **境界系统**：5个境界阶段（练气→筑基→结丹→元婴→化神）

### 4. 修练系统
- 点击"开始修练"按钮自动修练
- 每秒获得经验和境界经验
- 修练时界面会显示脉动效果

### 5. 境界突破
- 当境界经验达到上限时解锁突破功能
- 突破后属性大幅提升
- 境界经验需求递增

### 6. 实时战斗系统
- 自动生成不同等级的敌人
- 敌人类型：普通、精英、Boss（不同��度）
- 玩家可以进攻或使用技能
- 战斗日志实时显示
- 战斗获胜后获得经验和境界经验奖励

### 7. 技能系统
- **基础技能**：基础剑法（所有职业）
- **高阶技能**：
  - 剑宗：剑气风暴
  - 符宗：符文护盾
  - 丹宗：丹火锤炼
- **通用技能**：重击、疗伤术等

### 8. 装备系统
- 武器、防具、饰品、戒指装备槽
- 装备品质等级（白-蓝-紫-橙-红）
- 装备提供属性加成

### 9. 任务系统
- 多个主线任务
- 任务进度实时更新
- 任务完成后获得奖励
- 任务类型：击败敌人、升级、境界突破

### 10. 成就系统
- 游戏内多个成就
- 成就自动解锁
- 成就列表展示

### 11. 统计系统
- 追踪战斗胜利数
- 击败敌人总数
- 完成任务数
- 总伤害输出

## 游戏流程

1. **注册/登录** - 创建账户或使用已有账户登录
2. **创建角色** - 选择宗门和设置角色名
3. **开始游戏** - 进入主游戏界面
4. **战斗升级** - 通过战斗获得经验升级
5. **修练突破** - 修练获得境界经验，达到上限后可突破
6. **完成任务** - 完成各类任务获得奖励
7. **解锁成就** - 达成特定条件解锁成就

## 宗门特色

### 剑宗
- **特点**：攻击型，输出伤害高
- **特殊技能**：剑气风暴
- **优势**：高攻击力

### 符宗
- **特点**：防御型，防御能力强
- **特殊技能**：符文护盾
- **优势**：高防御力

### 丹宗
- **特点**：平衡型，生存能力强
- **特殊技能**：丹火锤炼
- **优势**：高生命值

## 技术栈

- **前端**：HTML5 + CSS3 + Vanilla JavaScript
- **存储**：浏览器 LocalStorage
- **设计**：科技风UI

## 如何运行

1. 克隆或下载项目
2. 用浏览器打开 `index.html`
3. 开始游戏！

## 保存机制

所有数据都保存在浏览器 LocalStorage 中，包括：
- 用户账户信息
- 角色数据
- 游戏进度
- 成就和统计
